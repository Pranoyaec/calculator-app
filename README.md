# Calculator App

A simple command-line calculator built in Python. This project was created as **Task 2** for the Python Programming Internship.

## Features
- Add, subtract, multiply, and divide two numbers
- Handles invalid input gracefully (non-numeric entries, division by zero)
- Lets you perform multiple calculations in one session

## How to Run
1. Make sure you have Python 3 installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/calculator-app.git
   cd calculator-app
   ```
3. Run the app:
   ```bash
   python calculator.py
   ```

## Example Usage
```
==== SIMPLE CALCULATOR ====
Operations: + (add), - (subtract), * (multiply), / (divide)

Enter first number: 5
Enter second number: 3
Choose an operation (+, -, *, /): +
Result: 8.0

Perform another calculation? (y/n): n
Goodbye!
```
